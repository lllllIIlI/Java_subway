# ☕ COFFEE PRINCESS

> Android 기반 모바일 카페 주문 애플리케이션

**COFFEE PRINCESS**는 기존 카페 키오스크의 주문 기능을 모바일 애플리케이션으로 구현한 프로젝트입니다.
사용자가 카페에 직접 방문하지 않고도 모바일 환경에서 메뉴를 확인하고 원하는 음료를 선택하여 주문 및 결제할 수 있도록 제작했습니다.

---

## 📱 프로젝트 소개

카페 키오스크의 주요 기능을 모바일 앱으로 구현하여 사용자의 **접근성과 주문 편의성**을 높이는 것을 목표로 개발했습니다.

사용자는 회원가입 및 로그인을 통해 개인 계정을 생성한 후 메뉴를 확인하고, 원하는 상품과 옵션을 선택하여 장바구니에 담을 수 있습니다. 이후 결제 방법을 선택하여 주문을 완료할 수 있습니다.

## 🎯 프로젝트 목적

모바일 앱을 통해 사용자가 언제 어디서나 카페 메뉴를 확인하고 주문할 수 있도록 하여, 카페에 직접 방문하지 않고도 주문할 수 있는 편의성을 제공하는 것을 목적으로 했습니다.

### 주요 목표

* 직관적인 사용자 인터페이스 구성
* 카페 메뉴 탐색 및 주문 과정 간소화
* 사용자 회원가입 및 로그인 기능 구현
* 메뉴 옵션을 통한 음료 커스터마이징
* 장바구니를 통한 주문 관리
* 결제 기능 구현
* 회원정보 조회 및 수정
* 회원 탈퇴 기능 구현

보고서에서는 사용자 편의성과 신속한 주문을 중심으로 UI/UX를 설계하고, 사용자의 선호도와 주문 내역을 활용한 맞춤형 음료 및 커스터마이징 기능을 목표로 제시하고 있습니다.

등록된 계정으로 로그인할 수 있습니다.

로그인 과정에서는 Google reCAPTCHA를 이용한 CAPTCHA 검증 기능도 구현되어 있습니다.

---

### 3. 회원정보 관리

로그인 후 메뉴를 통해 자신의 회원정보를 관리할 수 있습니다.

* 회원정보 조회
* 이메일 수정
* 비밀번호 수정
* 회원 탈퇴
* 회원 탈퇴 확인 모달

회원정보를 수정하면 데이터베이스의 사용자 정보가 업데이트되고, 회원 탈퇴를 진행하면 해당 사용자 정보가 데이터베이스에서 삭제됩니다.

---

### 4. 메뉴 조회

메뉴 화면에서는 카페에서 판매하는 상품을 확인할 수 있습니다.

메뉴는 카테고리별 탭으로 구분되어 있으며 프로젝트 구현에는 다음과 같은 메뉴 탭이 포함되어 있습니다.

* 전체 메뉴
* 커피
* 쥬스

상품은 `RecyclerView`를 기반으로 표시되며 상품의 이름, 가격, 이미지 등의 정보를 확인할 수 있습니다.

---

### 5. 상품 옵션 선택

상품을 선택하면 상세 옵션 화면으로 이동합니다.

음료에 대한 옵션을 선택하고 수량을 조절할 수 있으며, 옵션에 따라 최종 가격이 계산됩니다.

예시 옵션:

* 펄
* 샷
* 시럽

옵션을 선택한 후 **메뉴 담기**를 통해 장바구니에 상품을 추가할 수 있습니다.

---

### 6. 장바구니

선택한 상품을 장바구니에서 확인할 수 있습니다.

* 상품명 확인
* 수량 확인
* 가격 확인
* 동일 상품 수량 합산
* 장바구니 전체 삭제
* 결제 화면 이동

장바구니는 `RecyclerView`와 `CartAdapter`, `CartItem`을 이용하여 구현되어 있습니다.

---

### 7. 주문 및 결제

장바구니에 상품을 담은 후 결제를 진행할 수 있습니다.

**주문 과정**

```text
상품 목록
   ↓
상품 선택
   ↓
옵션 선택
   ↓
장바구니
   ↓
결제 방법 선택
   ↓
결제 완료
```

결제 화면에서는 결제 방법을 선택할 수 있으며, 결제가 완료되면 주문 완료 화면으로 이동합니다.

## 🔥 Firebase

프로젝트에서는 **Firebase Realtime Database**를 이용하여 회원 데이터를 관리합니다.

회원가입 시 `users` 아래에 사용자 ID를 기준으로 회원정보가 저장되며, 로그인 및 회원정보 조회·수정·삭제 과정에서도 Firebase Database를 사용합니다.

```text
Firebase Realtime Database
└── users
    └── 사용자 ID
        ├── Id
        ├── email
        └── password
```

## 실제 프로젝트 코드에서도 `FirebaseDatabase`와 `DatabaseReference`를 사용하여 사용자 데이터를 조회하고 추가·수정·삭제하는 구조를 확인할 수 있습니다.

## 📌 프로젝트를 통해 구현한 것

COFFEE PRINCESS를 통해 카페 키오스크의 핵심적인 사용자 경험을 모바일 환경으로 옮기는 것을 목표로 했습니다.

특히 다음과 같은 하나의 주문 흐름을 구현했습니다.

**회원 관리 → 메뉴 탐색 → 상품 커스터마이징 → 장바구니 → 결제**

이를 통해 Android 애플리케이션에서 화면 구성뿐만 아니라 데이터베이스 연동, 사용자 인증, RecyclerView 기반 데이터 표시, Activity 및 Fragment 간 화면 이동 등의 기능을 직접 구현했습니다.
